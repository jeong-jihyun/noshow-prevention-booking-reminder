실행
HTML 파일을 Chrome/Edge에서 열어 사용합니다. 모바일 폭에서는 하단 탭이 표시되고 데스크톱에서는 좌측 메뉴가 표시됩니다.
예약/대기자 등록, 상태 변경, 취소 후 대기자 제안, 제안 수락/거절/시간초과, 알림 설정, 노쇼 집계는 브라우저 localStorage 기반 데모로 동작합니다.

중요한 범위 고지
기준 GitHub 저장소는 Python CLI + SQLite 로컬 도구입니다. 실제 SMS/알림톡 발송, 고객 답장 Webhook, 로그인/권한, 서버 API는 구현되어 있지 않습니다.
본 프로토타입은 UI/화면 흐름 확인용이며 실제 발송이나 운영 DB 변경을 수행하지 않습니다. API 설계서는 향후 서버화 시 적용할 제안안입니다.
